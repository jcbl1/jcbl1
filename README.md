## 👨‍💻 About Me

- 🎓 Master's student in Software Engineering @ **Wuhan University of Technology**
- 💼 **Backend engineer & maintainer** — mostly **Java / Spring** and **Go**
- 🏗️ I build **distributed services** with an emphasis on stability, clean architecture, and delivery that stays reproducible through containers and CI/CD
- 🤖 Currently drawn to **AI-native development** — wiring LLMs, retrieval, and tool calling into real systems with **Spring AI**
- 🌐 I write about backend engineering and more on my [blog](https://blog.yelr.de)
